# GDG - DSA Resource Sheet
*Curated for GDG DSA Workshop — First Year BE Students*

Bookmark this. You don't need all of these — pick 1-2 from each section and stick with them.

---

## Start Here (Concept Building)

| Resource | Why |
|---|---|
| **Abdul Bari** (YouTube) | Best for building intuition — clear visual explanations of core DS/algo concepts |
| **Striver's A2Z DSA Sheet** (YouTube + takeuforward.org) | Structured, step-by-step roadmap from zero to advanced |
| **NeetCode** (YouTube) | Great for pattern-based problem solving once you know basics |
| **CPH (Competitive Programmer's Handbook)** — free PDF | Concise reference once you've seen a topic once |
| **GeeksforGeeks** | Quick lookup for syntax, definitions, and standard implementations |

**New additions worth adding:**
- **Kunal Kushwaha's DSA Playlist** (YouTube) — free, structured, popular with first-years
- **VisuAlgo** (visualgo.net) — *interactive* visualizations of arrays, stacks, queues, trees, sorting — genuinely helps when something doesn't click from video alone
